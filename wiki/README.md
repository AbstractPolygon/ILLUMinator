# Wiki sources

The pages of the [ILLUMinator wiki](https://github.com/AbstractPolygon/ILLUMinator/wiki). To publish changes:

```
git clone https://github.com/AbstractPolygon/ILLUMinator.wiki.git
cp wiki/*.md ILLUMinator.wiki/ && rm ILLUMinator.wiki/README.md
cd ILLUMinator.wiki && git add -A && git commit -m "Update wiki" && git push
```
