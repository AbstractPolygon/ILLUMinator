- **Cleaner depth on shiny things.** Black blotches on metal and glass in the depth map are gone.
- **Diamond pattern fix.** Large full sensor renders (3× and 4×) no longer show a faint diamond grid in blurry areas. A new *Lattice filter* setting lets you adjust it.
- **Better upscaling.** Each upscaling method now keeps its settings, and the extra upscaling and depth models can be downloaded in the web version too.
- **Smarter lens alignment.** A new *Lens centers* setting uses your camera's calibration for more accurate renders.
